# เช็คเลนวิ่ง Mini 4WD

เว็บแอปหน้าเดียว (ใช้บนมือถือได้) ก๊อปตารางรอบแข่งมาวาง แล้วพิมพ์ชื่อทีม
แอปจะบอกจำนวนทีมทั้งหมด และทีมคุณวิ่งรอบไหน เลนอะไร พร้อมคู่แข่งในรอบนั้น

เปิด `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องติดตั้ง) ทดสอบตัวอ่านข้อมูล: `node test.js`

รูปแบบที่อ่านได้: `รอบที่ 1 / เลน 1 ชื่อ`, ตารางแท็บ (`1 <tab> A <tab> B ...`),
`Round 1: L1 A | L2 B`, และรายการ `Heat 1` ตามด้วยชื่อเรียงตามเลน
